## 🛠 Implementation Details

To ensure these systems function correctly within your environment, please note the following architectural requirements:

* **Environment:** Designed for the Luau language on the Roblox engine.
* **Structure:** Most scripts expect a standard `Aero` or `Knit`-style folder structure, though they are largely decoupled.
* **Dependencies:** Check the `init.lua` or the top of scripts for required ModuleScripts located in `ReplicatedStorage`.
